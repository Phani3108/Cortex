Why Cortex

Your team uses four AI tools. They are following four different rulebooks.

Every tool reads a different file, in a different format, with different limits — and the copies drift the week after you write them.

Without Cortex
  • The same rules pasted into CLAUDE.md, .cursor/rules, Copilot instructions and AGENTS.md
  • Windsurf silently cuts rule files past 12,000 characters; Antigravity past 24 KB
  • Tools that read AGENTS.md and their own file load your rules twice
  • Nobody notices the copies drifted until an agent does the wrong thing
With Cortex
  • One markdown source in .cortex/, reviewed like code
  • Hard limits enforced by keeping your highest-impact rules, whole — and telling you what didn’t fit
  • Path-scoped rules become native globs; skills become portable SKILL.md
  • cortex compile --check fails CI the moment anything drifts

How it works

        
Three commands. Then it runs itself.

      

      

        

          
1

          
Init

          
Detects your stack and the AI tools you already use, and imports hand-written CLAUDE.md / AGENTS.md / Cursor / Copilot files so nothing is lost.

          
cortex init

        

        

          
2

          
Compile

          
Writes each tool’s native files. Refuses to overwrite files a human wrote or edited, and cleans up files it no longer generates.

          
cortex compile

        

        

          
3

          
Guard

          
Commit the sources and the outputs (cloud agents read them from the repo). CI fails when they drift; cortex learn turns your edits into rule suggestions.

          
cortex compile --check

What’s inside

        
A build system for AI context.

      

      

        

          

          
Model-aware formatting

          
XML sections for Claude, numbered lists for GPT, context-first for Gemini, compact constraints for reasoning models. Set a model per tool and the output follows.

        

        

          

          
Budget-aware, never truncated

          
Hard limits are met by keeping whole, high-impact rules — critical rules (- !) first — and listing exactly what was left out.

        

        

          

          
Path-scoped rules

          
Add scope: ["src/**/*.tsx"] to a rule file. Cortex emits Cursor globs, Copilot applyTo, Claude paths, Kiro fileMatch and Windsurf glob triggers.

        

        

          

          
Agent Skills, portable

          
Skills compile to the open SKILL.md standard in .claude/skills, .agents/skills and .kiro/skills — loaded on demand, not stuffed into every prompt.

        

        

          

          
Safe by default

          
Hand-written or hand-edited files are never overwritten without --force. cortex init imports what you already have first.

        

        

          

          
Live model data

          
Pricing and context windows for 200+ models, refreshed daily by a GitHub Action. cortex cost tells you what your always-on context really costs.
