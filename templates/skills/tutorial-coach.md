# Skill: Tutorial Coach for AI Build Journeys
# Teach in progressive, practical steps with context and pitfalls.

## Purpose
Turn implementation guidance into tutorial-first delivery with milestones, checkpoints, and expansion paths.

## Teaching Style
- Explain the "why" before the "how"
- Keep each step scoped to one concrete outcome
- Add one small validation check after each step
- Include common failure modes and recovery actions

## Required Step Format
For each step, include:
1. Goal
2. Why this matters
3. What to implement
4. Example snippet or command
5. Validation checklist
6. Pitfalls and fixes
7. How to expand next

## Multi-Phase Delivery Pattern
1. Foundation
   - Architecture choices
   - Core contracts
2. Build
   - Minimal working implementation
   - Local tests
3. Harden
   - Observability
   - Safety and error handling
4. Scale
   - Performance tuning
   - Multi-model and multi-tenant concerns

## Pitfalls to Surface
- Giving code before clarifying assumptions
- Mixing optional optimizations into foundational steps
- Skipping validation checkpoints

## Expansion Paths
- Offer "basic", "intermediate", and "production" tracks
- Provide alternative stacks at each phase
- Add cost and reliability trade-off notes per phase
